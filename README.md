# Meowse Homebrew tap

Install [Meowse](https://meowse.app) with [Homebrew](https://brew.sh):

```sh
brew install --cask salvcy/tap/meowse
```

Meowse updates itself, so `brew upgrade` leaves it alone unless you pass `--greedy`.

To remove it, along with its settings:

```sh
brew uninstall --zap --cask meowse
```
